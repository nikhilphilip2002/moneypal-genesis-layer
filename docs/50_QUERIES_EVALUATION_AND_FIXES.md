* **Problem**: In `backend/app/services/nlq/analyses/quadrant.py`, the quadrant composer computes medians on both axes and requires at least 4 distinct dimension points to populate 4 quadrants. When the test dataset has only 1 or 2 products, it emits 0 findings with `"Not enough members to compare."`
* **Proposed Code Fix** (`backend/app/services/nlq/analyses/quadrant.py`):
```python
# Fallback when distinct members < 4
if len(points) < 4:
    ranked_findings = [
        Finding(
            id=f"member_{p.label}",
            label=p.label,
            text=f"{p.label}: {format_value(p.x, x_metric.unit)} {x_metric.label}, with {format_value(p.y, y_metric.unit)} {y_metric.label}.",
            severity="watch" if p.y > y_cut else "info"
        )
        for p in points
    ]
    return AnalysisResult(
        title=definition.title,
        headline=f"Comparative performance across {len(points)} available member(s).",
        findings=ranked_findings,
        chart=build_ranked_bar_chart(points, x_metric, y_metric)
    )
```

### 🔧 Fix 2: Identifier / Account Number Formatting Fix (Fixes `10,00,40,00,01,498`)
* **Problem**: In `frontend/components/nlq/chartTheme.ts`, `formatValue(value, unit)` treats numeric account numbers as standard quantities and formats them via `toLocaleString('en-IN')`, inserting Lakh/Crore grouping commas into loan account numbers, customer IDs, and PIN codes.
* **Proposed Code Fix** (`frontend/components/nlq/chartTheme.ts`):
```typescript
export function formatValue(value: unknown, unit: string): string {
  if (value === null || value === undefined) return '—';
  
  // Guard: Text/Identifier fields must NEVER be formatted with numerical grouping
  if (unit === 'text' || unit === 'date' || unit === 'datetime') {
    return String(value);
  }
  if (typeof value !== 'number') return String(value);

  switch (unit) {
    case 'text':
      return String(value);
    case 'inr': { ... }
    case 'percent': { ... }
    case 'count':
    case 'days':
      return value.toLocaleString('en-IN', { maximumFractionDigits: 0 });
    default:
      return value.toLocaleString('en-IN', { maximumFractionDigits: 2 });
  }
}
```
