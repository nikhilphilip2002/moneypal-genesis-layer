# Glossary — Genesis Intelligence Layer

Abbreviations and terms used in `GENESIS_INTELLIGENCE_LAYER.md`.

| Term | Meaning |
|---|---|
| **LOS** | Loan Origination System — handles customer onboarding, loan application, and approval. Prosper plays this role. |
| **LMS** | Loan Management System — handles the loan lifecycle after disbursement: repayments, collections, portfolio tracking. Prosper plays this role. |
| **GL** | General Ledger — the core accounting record (chart of accounts, journal entries, trial balance). Tally ERP plays this role. |
| **ERP** | Enterprise Resource Planning — Tally ERP is the accounting/finance system used for the GL. |
| **GRC** | Governance, Risk & Compliance — the persona/module concerned with regulatory exposure: "What does the regulator think about us?" |
| **NBFC** | Non-Banking Financial Company — the regulatory category GICC (and similar lenders) fall under in India. |
| **DNBS** | Department of Non-Banking Supervision (RBI) — the regulatory return/report NBFCs file; "DNBS report" = the specific filing due as on 30-06-2026. |
| **RBI** | Reserve Bank of India — the banking/NBFC regulator referenced throughout the GRC module. |
| **COA** | Chart of Accounts — the structured list of GL account categories used in Tally. |
| **P&L** | Profit & Loss statement — a core financial report derived from the GL. |
| **PAR** | Portfolio at Risk — the proportion of a loan portfolio overdue by a given number of days (e.g. PAR 30/60/90 = overdue 30/60/90+ days), used as a portfolio quality / early-warning metric. |
| **DPD** | Days Past Due — how many days a repayment is overdue; used to bucket loans by risk. |
| **AUM** | Assets Under Management — total loan book / portfolio value managed by the institution. |
| **NPA** | Non-Performing Asset — a loan in default per regulatory definition; relevant to portfolio quality and regulatory ratios. |
| **ROI** | Return on Investment — the finance persona's core metric, computed per portfolio. |
| **MoM / QoQ / YoY** | Month-over-Month / Quarter-over-Quarter / Year-over-Year — the standard self-comparison periods used in Module 2 (Competitive/Self Intelligence). |
| **RAG** | Retrieval-Augmented Generation — the AI technique used by the *existing* Moneypal platform (`BUILDATHON_PLAN.md`) to summarize unstructured PDFs; contrasted in the Genesis doc with the new transactional/data-driven approach, which does not need RAG. |
| **GICC** | GICC, Ltd. — the specific lender client Sprint 1 is scoped to. |
| **CEO / CFO** | Chief Executive Officer / Chief Financial Officer — the executive personas the Business and Finance dashboards are built for. |
