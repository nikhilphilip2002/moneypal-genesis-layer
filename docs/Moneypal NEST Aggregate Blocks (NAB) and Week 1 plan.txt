Moneypal  NEST  Aggregate  Blocks  (NAB)  
Technical  Developer  Brief  
Version  1.0  
 
1.  Purpose  
The  NEST  Aggregate  Block  (NAB)  is  the  canonical  business  record  for  every  business  entity  
in
 
the
 
Moneypal
 
ecosystem.
 
Unlike  a  traditional  relational  database  where  rows  are  continuously  updated,  a  NAB  records  
every
 
business
 
event
 
as
 
an
 
immutable
 
append-only
 
event
.
 
The  current  state  of  an  Enterprise,  Person,  Loan  or  Household  is  always  reconstructed  by  
replaying
 
its
 
events.
 
Think  of  a  NAB  as  a  Git  repository  for  a  business  object .  
Nothing  is  overwritten.  
Everything  is  versioned.  
Everything  is  explainable.  
 
2.  Design  Principles  
Every  NAB  shall  satisfy  the  following  principles:  
●  Immutable  ●  Append-only  ●  Event-driven  ●  Aggregate-oriented  ●  Time  ordered  ●  Versioned  ●  Replayable  ●  Auditable  ●  AI-readable

●  API  accessible

11.  Snapshots  
Replaying  10,000  events  can  become  expensive.  
Every  100  events:  
Create  Snapshot.  
Events  
 
↓  
 
Replay  
 
↓  
 
Snapshot  
 
↓  
 
Replay  remaining  events  
 
Snapshots  are  cache.  
Events  remain  source  of  truth.

21.  Definition  of  Success  
The  NAB  implementation  will  be  considered  successful  when  it  can:  
1.  Create  any  Aggregate  from  a  sequence  of  immutable  events.  2.  Replay  events  to  reconstruct  the  current  state.  3.  Produce  snapshots  without  altering  event  history.  4.  Support  append-only  event  creation  with  optimistic  concurrency  control.  5.  Build  independent  projections  for  analytics,  regulatory  reporting  and  AI.  6.  Accept  migrated  data  from  legacy  systems  by  converting  records  into  canonical  
events
 
rather
 
than
 
database
 
updates.
